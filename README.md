# COSMOS — Black Hole

Versão própria de uma experiência WebGL de buraco negro, criada do zero com Three.js e GLSL.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra a URL mostrada pelo Vite.

## Publicar na Vercel

1. Crie um repositório no GitHub.
2. Envie estes arquivos.
3. Na Vercel, importe o repositório.
4. Framework: Vite.
5. Build command: `npm run build`
6. Output directory: `dist`

## Controles

- Arraste o mouse para interagir com a cena.
- Use a roda do mouse para aproximar/afastar.
- O efeito é procedural: estrelas, disco de acreção, turbulência, brilho e horizonte são gerados no shader.

## Observação

Este projeto é uma implementação independente inspirada no conceito visual de uma simulação de buraco negro. Não copia os arquivos-fonte do projeto de referência.
